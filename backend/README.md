# Google Apps Script 백엔드 배포

이 백엔드는 GitHub Pages 화면에 공용 로그인과 저장소를 제공합니다. 기존 `workstudent-manager`의 Apps Script 프로젝트나 URL은 사용하지 않습니다.

현재 서울 시스템용 Apps Script 프로젝트의 `Code.gs`를 이 파일로 교체한 뒤 새 버전으로 배포합니다. 기존 운영 데이터는 실제 배포본이 사용하는 `swtm2` 키에 그대로 남고, 기존 계정 해시와 세션도 호환되며, 읽기/저장 시 v4 구조로 자동 정규화됩니다. `initialize()`는 데이터가 없는 최초 설치에서만 사용하며 기존 데이터가 있으면 아무것도 덮어쓰지 않습니다.

1. 배포 전에 관리 화면의 **데이터 관리**에서 전체 JSON 백업을 내려받습니다.
2. 서울 시스템 전용 Apps Script 프로젝트의 `Code.gs`를 갱신합니다.
3. **배포 → 배포 관리 → 수정 → 새 버전**으로 웹 앱을 갱신합니다.
4. 실행 사용자는 본인, 액세스 권한은 현재 배포 설정을 유지합니다.
5. 기존 `/exec` URL이 유지되는지 확인하고 관리자·학생 로그인을 각각 테스트합니다.

신규 설치만 프로젝트 설정의 **스크립트 속성**에 `INITIAL_ADMIN_PASSWORD`를 추가한 후 편집기에서 `initialize()`를 한 번 실행합니다.

초기 관리자 아이디는 `admin`입니다. 초기 비밀번호는 스크립트 속성 값이며, 첫 로그인 후 계정 관리에서 변경합니다.

학생 API 응답에는 다른 근무지 데이터, 다른 학생 명단, 학번·전화번호·이메일, 계정 목록, 예산액, 다른 학생의 구인 신청자·근태가 포함되지 않습니다. 대타와 추가근무의 근무지·일정 충돌·정원, 출퇴근의 실근무자·중복 여부, 관리자 근태 보정을 서버에서 다시 검증합니다.
