# 서울 근로장학생 관리 시스템

서울 총무팀 검토용 웹 시안입니다. 총무팀과 HOLMZ의 학생 및 근무 일정을 분리하여, 오늘 근무·주간 시간표·월간 시간표·학생 관리·반복 일정 관리를 제공합니다.

## 주요 기능

- `총무팀` / `HOLMZ` 워크스페이스 즉시 전환
- 현재 시각 기준으로 분류한 오늘의 근무자
- 겹치는 일정을 나란히 표시하는 PC용 주간 시간표와 모바일용 일자 카드
- 반복 일정과 날짜 지정 일정을 함께 보여주는 월간 시간표
- 학생 추가, 수정, 활성/비활성, 삭제
- 일정 추가, 수정, 삭제 및 주간 반복 설정
- 학생/관리자 개별 로그인과 관리자 계정 발급·비밀번호 변경
- 공지사항, 인수인계, 학생 대타 요청 및 관리자 처리
- Apps Script 기반 공용 저장소 모드와 JSON 데이터 내보내기/가져오기

## 초기 데이터

`data/seed.json`에는 제공된 2026년 9월 총무팀 주간표와 HOLMZ 시간표 이미지에서 판독 가능한 학생·요일·시간만 반영했습니다. 색상에는 업무상 의미를 부여하지 않았습니다.

## 기술 구조

프레임워크 의존성이 없는 정적 웹 앱입니다. GitHub Pages 화면은 `config.js`의 Apps Script 웹 앱 API와 연결되어 학생/관리자 세션, 계정, 일정, 공지, 인수인계, 대타 요청을 공유 저장합니다. `backend/Code.gs`는 서울 총무팀용으로 새로 만든 독립 Apps Script 프로젝트에 배포합니다. 기존 운영 프로젝트와 API는 수정하거나 재사용하지 않습니다.

## 로컬 실행

```bash
npm test
npm start
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 배포

GitHub Pages의 **Deploy from a branch**에서 기본 브랜치와 `/(root)`를 선택합니다. 정적 파일만 사용하므로 별도 빌드는 필요 없습니다.

## 실제 운영 전 검토 사항

- 여러 담당자가 같은 데이터를 공유하려면 로그인 권한과 서버 DB를 추가해야 합니다.
- 브라우저 저장 데이터는 기기와 브라우저마다 독립적입니다. 현재는 검토용 시안이므로 JSON 내보내기/가져오기를 제공합니다.
- 실제 운영 전에는 개인정보 최소화 원칙, 백업 주기, 데이터 보존 기준을 확정해야 합니다.
