# 서울 근로장학생 관리 시스템

서울 총무팀과 HOLMZ를 하나의 시스템에서 분리 운영하는 근로장학생 관리 포털입니다. 관리자에게는 전체 운영 현황을, 학생에게는 본인의 일정과 같은 근무지의 업무 정보만 제공합니다.

## 주요 기능

- 관리자 첫 화면의 오늘·주간·월간·중요 공지·대타·예산 통합 대시보드
- 총무팀 평일 5일 / HOLMZ 주말 포함 7일 주간 시간표
- 학생별 관리자 지정 색상과 개인용 모바일 근로 포털
- 학생 본인의 JPG/PNG 증명사진 등록·변경, 시간표 상세 정보와 학생 관리 썸네일
- 학번·전화번호·이메일 관리자 전용 관리
- 반복 일정 위에 적용하는 날짜별 취소·시간 변경·임시 추가근무
- 동일 근무지 안에서만 가능한 대타 요청·가져가기·관리자 확정
- 학생 개인 월간 달력, 다가오는 일정 카드, 날짜별 근무 상세
- 정원·일정 충돌을 서버에서 검사하는 추가근무 구인·신청·관리자 확정
- 일정 인스턴스별 필수 출근, 정상 퇴근 자동처리, 조기퇴근 및 관리자 보정 이력
- 전체/근무지별 중요 공지와 Google Drive 링크형 인수인계
- 지난 근무의 실제 인정시간과 미래 예정시간을 분리한 예산 전망
- 과거 학기 보관과 선택적 학생·색상 복사를 지원하는 학기 관리
- v1 백업을 포함한 이전 데이터의 비파괴 마이그레이션과 전체 JSON 백업
- Apps Script 서버 단계의 역할·근무지 필터와 학생 개인정보 제거

증명사진은 공개 URL을 만들지 않고 전용 Google Drive 폴더에 비공개로 저장합니다. 학생은 자신의 사진만, 관리자는 학생 관리와 시간표의 학생 상세 화면에서만 사진을 확인할 수 있습니다.

## 초기 데이터

`data/seed.json`의 기존 학생과 근무 일정은 그대로 보존했습니다. 학생 색상은 사람 식별 용도이며 근무 인원이나 업무 상태를 뜻하지 않습니다. 개인정보와 예산·단가는 담당자가 확인한 값만 입력하도록 빈 값으로 둡니다.

## 기술 구조

프레임워크 의존성이 없는 정적 웹 앱입니다. GitHub Pages 화면은 `config.js`의 Apps Script 웹 앱 API와 연결됩니다. 관리자는 전체 데이터, 학생은 본인 정보(민감 필드 제외)와 본인 근무지의 현재 학기 데이터만 서버에서 받습니다. `backend/Code.gs`는 서울 시스템 전용 Apps Script 프로젝트에 배포하며 기존 `workstudent-manager`는 수정하지 않습니다.

## 데이터 호환성

기존 `students`, `schedules`, `accounts`, `notices`, `handovers`, `swaps`는 유지됩니다. 앱과 서버가 읽을 때 v4 구조로 정규화하며 누락된 `extraJobs`, `attendances`, `attendanceAudit`를 빈 배열로 보강합니다. 과거 일정에 가짜 출퇴근 기록은 만들지 않습니다. 실제 운영 데이터 키 `swtm2`와 기존 계정 해시 형식을 계속 읽으므로 별도의 파괴적 이전 작업이 없습니다.

## 로컬 실행

```bash
npm test
npm start
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 배포

GitHub Pages의 **Deploy from a branch**에서 기본 브랜치와 `/(root)`를 선택합니다. 정적 파일만 사용하므로 별도 빌드는 필요 없습니다.

## 담당자 확인 사항

- 총무팀과 HOLMZ의 실제 시간당 단가 및 예산액
- 학기 시작일·종료일과 예산 계산에 포함할 휴게시간 규칙
- 대타 확정 권한과 실제 지급·근무 인정 기준
- 출근 허용 시간 범위, 휴게시간, 분 단위 처리·반올림, 확정 추가근무 취소 절차
- 개인정보 보존 기간, 접근 담당자, 정기 백업 주기
